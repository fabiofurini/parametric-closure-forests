# Instance generation

How every benchmark instance is built: the topology families and the
affine-coefficient families. For the on-disk `.pcf` grammar those
instances are written in, see [`INSTANCE_FORMAT.md`](INSTANCE_FORMAT.md).
For which combinations of these families make up each official campaign,
see [`EXPERIMENTAL_PROTOCOL.md`](EXPERIMENTAL_PROTOCOL.md).

Every instance is generated by a seeded, deterministic script
(`tools/generate_random_instances.py`, `tools/generate_structured_instances.py`,
`tools/pcf_families.py`) and manifested with its SHA-256 checksum, topology
classification and coefficient bounds (`instances/manifests/`). No instance
file is ever hand-edited.

## Topology families

| Topology | Construction rule | Degree / shape |
|---|---|---|
| `mixed-forest` | Connect each item $v\in\{2,\dots,n\}$ to a uniformly chosen predecessor $u<v$, independently with probability $\rho$ (the density); orient each resulting edge as $(u,v)$ or $(v,u)$, each with probability $1/2$. | General forest |
| `in-forest` | Scan $u\in\{1,\dots,n-1\}$; independently with probability $\rho$, add arc $(u,j)$ with $j$ uniform on $\{u{+}1,\dots,n\}$. | Out-degree $\le 1$ everywhere |
| `out-forest` | Scan $v\in\{2,\dots,n\}$; independently with probability $\rho$, add arc $(u,v)$ with $u$ uniform on $\{1,\dots,v{-}1\}$. | In-degree $\le 1$ everywhere |
| `path-mixed` | Fixed path shape (item $v$'s parent is item $v-1$); orient every edge independently, each with probability $1/2$. | Path, no $\rho$ |
| `binary-mixed` | Fixed balanced binary tree (item $v$'s parent is item $\lfloor(v-1)/2\rfloor$); orient every edge independently, each with probability $1/2$. | Binary tree, no $\rho$ |
| `star-mixed` | Fixed star (every item $v>0$'s parent is item $0$); orient every edge independently, each with probability $1/2$. | Star, no $\rho$ |

Density $\rho\in\{0.3, 0.6, 0.9, 1.0\}$ applies only to the three random
topologies (`mixed-forest`, `in-forest`, `out-forest`); $\rho=1.0$ gives a
connected spanning tree. The three structured families are always a
complete tree on $n$ items — only the arc orientations are randomized.

## Affine-coefficient families

Six families, chosen only for the shape of the resulting ratio
$p_i/w_i$, never for any external classification. Weight $w_i$ is always
drawn strictly positive; profit $p_i$ may be signed.

| Family | $w_i$ | $p_i$ | Shape |
|---|---|---|---|
| `independent-positive` | $\mathrm U\{1,\dots,1000\}$ | $\mathrm U\{1,\dots,1000\}$, independent of $w_i$ | Dispersed, positive ratios |
| `independent-signed` | $\mathrm U\{1,\dots,1000\}$ | $\mathrm U\{-1000,\dots,1000\}$, independent of $w_i$ | Some items locally unfavorable |
| `correlated` | $\mathrm U\{1,\dots,1000\}$ | $w_i+\delta_i$, $\delta_i\sim\mathrm U\{-50,\dots,50\}$ | Ratios concentrated near 1 |
| `anti-correlated` | $\mathrm U\{1,\dots,1000\}$ | $(1001-w_i)+\delta_i$, $\delta_i\sim\mathrm U\{-50,\dots,50\}$ | More heterogeneous ratios |
| `near-ties` | $\mathrm{den}\cdot t_i$ | $\mathrm{num}\cdot t_i+\jmath_i$ | Many items share a common ratio up to a small perturbation |
| `exact-ties` | $\mathrm{den}_g\cdot t_i$ | $\mathrm{num}_g\cdot t_i$ | Groups of items share one exact ratio |

`near-ties`: a target ratio $\mathrm{num}/\mathrm{den}$ is drawn once per
instance ($\mathrm{num},\mathrm{den}$ uniform on $\{1,\dots,20\}$); for
each item $i$, $t_i$ is uniform on $\{1,\dots,50\}$, and jitter
$\jmath_i$ is uniform on $\{-2,-1,1,2\}$ — stresses exact rational
comparisons between near-equal but distinct thresholds.

`exact-ties`: the $n$ items are split into $\max(1,\lfloor n/20\rfloor)$
groups, each assigned its own exact ratio $\mathrm{num}_g/\mathrm{den}_g$
(drawn uniformly on $\{1,\dots,20\}^2$); for an item $i$ in group $g$,
$t_i$ is uniform on $\{1,\dots,50\}$, so every item in a group shares the
exact same ratio $p_i/w_i=\mathrm{num}_g/\mathrm{den}_g$ — stresses the
canonicalization rule that merges consecutive closure layers at an equal
threshold.
