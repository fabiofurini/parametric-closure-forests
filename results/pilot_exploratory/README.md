# Pilot / exploratory runs (superseded)

The reports and raw CSVs in this folder are preliminary investigations that
predate the official campaigns (A-F, see `docs/EXPERIMENTAL_PROTOCOL.md`).
Each report says so explicitly ("pilot validation only", "does not replace
the preregistered complete random campaign", etc.).

None of these numbers are cited in the manuscript or in any other doc in
this repository, and none are included in the packaged release
(`tools/package_release.sh` zips only `results/raw`, `results/processed`,
`results/tables` and `results/logs`, not this folder).

They are kept (not deleted) purely as a record of the exploratory work that
led to the official campaign design. For the numbers actually used in the
paper, see `results/raw/campaign_*.csv`, `results/processed/`, and
`results/processed/results_summary.json`.
